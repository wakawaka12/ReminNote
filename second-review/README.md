# ReminNote 二审报告目录

本目录只存放对 `D:\Anime\reviews` 中一审报告的二审裁决，不存放源代码修改或一审原文。

## 文件命名

- 建议格式：`<一审文件名>-second-review.md`
- 每份报告应注明：审查日期、审查范围、一审源文件、对应集成提交哈希。

## 单项裁决字段

每条一审发现至少包含以下二审信息：

1. 发现编号与一审主张
2. 代码或文档证据（文件与精确行号）
3. 二审裁决：接受、驳回、部分接受或信息不足
4. 校正后的严重级别与理由
5. 建议的最小处理方案及受影响文件
6. 是否阻断当前阶段

报告需明确区分“必须修复”和“可选改进”。二审只裁决一审结果；核实过程中发现的重大问题应单列为“二审额外发现”。
