# ReminNote

ReminNote 是面向 Windows 的提醒与个人记录应用。

当前仓库处于 P0-03 ReminNote Design System foundation：已建立可启动的 WPF 导航壳、Host/MVVM 基础和可复用视觉资源，尚未实现真实业务功能。请先阅读：

- `ReminNote_MASTER_DEVELOPMENT_PLAN.md`
- `PRODUCT_RULES.md`
- `ARCHITECTURE.md`
- `DEVELOPMENT.md`
- `TESTING.md`
- `DECISIONS.md`
- `docs/slices/P0-02-implementation-brief.md`
- docs/slices/P0-03-implementation-brief.md

运行前需要安装 .NET 10 LTS SDK。
