# ReminNote

ReminNote 是面向 Windows 的提醒与个人记录应用，目标是提供本地优先、可验证且严格开源的 Task 工作流。

当前仓库已完成 P1 的 Task 领域、SQLite 持久化和应用边界；P2 正在把真实 Task loop 接入 TODAY 与 Widget。Reminder 调度、Agent/IPC、同步和 Anime 网络功能尚未实现。
