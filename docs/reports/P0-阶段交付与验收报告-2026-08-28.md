## 终审整改落实

### P-1：Widget 确定性行为缺陷

- `IMP-1`：完成、延后、改期命令写入任务状态后，均通知 `TaskStatusLabel`；右上角状态标签会随操作刷新。
- `IMP-2`：标记提醒已读后关闭 Reminder Drawer，反馈写入独立的 `ReminderFeedback`，不再复用 Quick Add 反馈，也不再设置 `IsQuickAddOpen`。
- 反馈显示位置：Widget footer 的公共反馈区；提醒反馈仍明确标注为 Mock，不写入 `ReminderInstance`。

涉及文件：

- `src/windows/ReminNote.Widget/ViewModels/WidgetViewModel.cs`
- `src/windows/ReminNote.Widget/WidgetWindow.xaml`

### P-2：焦点与高对比度风险

- Today `TodayTextBoxStyle` 的键盘焦点边框改用共享 `AccessibleFocusBrush`。
- Anime `AnimeSearchTextBoxStyle` 增加 `IsKeyboardFocused` 触发器，并使用 `AccessibleFocusBrush`。

涉及文件：

- `src/windows/ReminNote.Windows/Features/Today/TodayResources.xaml`
- `src/windows/ReminNote.Windows/Features/Anime/AnimeResources.xaml`

本次按终审建议暂缓：Typography 重复 Setter 整理、额外资源反向门禁、`clean.ps1` 链接/重解析点安全加固和其他 NIT 清理。

## 验证证据

### 构建与仓库门禁

以下命令在 Windows SDK 可访问环境中通过：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1 -Configuration Release
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\test.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify-p0-07.ps1
```

结果：Release 构建 0 警告、0 错误；P0-07 门禁通过，检查到 213 个资源键、6 个锁定项目，并检查 Shell/TODAY/ANIME/Widget 的 UI Automation 标记。当前没有测试项目，因此 `test.ps1` 成功不代表业务测试覆盖；真实测试项目应在 P1 领域逻辑落地后建立。

### 自动化桌面交互冒烟

在设置 `WINDIR=C:\WINDOWS` 后启动 Release EXE，结果如下：

- Main App：主窗口启动、`动画`/`今天`导航切换通过。
- Widget：`完成` 后状态变为“已完成”；`延后` 和 `改期` 的反馈刷新通过。
- Widget：打开提醒抽屉并执行“标记当前提醒已读”后，独立提醒反馈可见，Quick Add 专属编辑框不可见。
- 上述进程在验证结束后已关闭，未留下运行中的项目进程。

自动化冒烟不能代替人工检查文字裁切、焦点颜色、高对比度和实际视觉层级。

### 数据与边界

- `.gitignore` 将 `bin/`、`obj/`、`.devdata/*`、日志和测试产物隔离。
- P0 代码只使用进程内 Mock；没有 SQLite、Token、网络缓存、生产配置或真实用户数据路径。
- `ReminNote.Core` 保持无 WPF、EF Core、Serilog 和 Windows API 依赖。
- Widget 通过项目文件 Link 复用 Design System 和默认资源，不复制资源字典，也不反向引用整个 Windows 程序集。
